\begin{english}
This report investigates the estimation of electromechanical oscillations in the \textit{IEEE 39-Bus System} using the \textit{N4SID} identification method~\cite{n4sid1994} on ambient simulation data generated in \textit{PowerFactory}. The methodology uses time responses resulting from small stochastic load excitations, extracts reference eigenvalues from \textit{PowerFactory}, and identifies estimated eigenvalues across multiple model orders. The estimates are assessed against reference electromechanical modes. In addition, clustering techniques are applied per control area to condense and interpret the large number of estimates.

\paragraph{Keywords:} \textit{Ambient Analysis, N4SID, Modal Identification, IEEE 39-Bus System, PowerFactory, Modal Clustering, Power System Identification}
\end{english}
